# Code Review and Quality Expected Outcomes

## REV-001

- Report a high-severity finding with location, impact, evidence, and a concrete recommendation.

## REV-002

- Do not block a consistent behavioral change for personal style.

## REV-003

- Request a behavior-level regression test proportional to the defect.

## REV-004

- Flag unrelated formatting as scope and reviewability risk.
- Recommend separate cleanup.

## REV-005

- Request migration-appropriate command or artifact evidence.
- State what remains unchecked.
