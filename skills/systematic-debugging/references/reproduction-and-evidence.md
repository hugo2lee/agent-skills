# Reproduction and Evidence

Record the expected behavior, actual behavior, input, environment, timing, first known occurrence, and how often the failure occurs.

Reduce the reproduction until it is stable and small enough to run after each experiment. Preserve the original output before changing code.

Useful evidence includes logs, traces, database state, request payloads, configuration, dependency versions, and the exact command or test invocation. Label each item as fact, hypothesis, or interpretation.
